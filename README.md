## Setup

To run locally:

1. Install Bun >= `1.4`
1. Clone the repo
1. Run `bun i`

> _**NOTE**: You'll also need the required Cloudinary environment variables set/_

You can now run these npm scripts
- `bun run dev` - Start the project with Greenwood's local dev server
- `bun run start` - Start the project with a production Greenwood build
